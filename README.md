# Portfólio — João Pedro Chiachio

Site pessoal com minha trajetória em **Inteligência Artificial, automação e desenvolvimento de software**: sobre mim, experiência, projetos em destaque, tecnologias, formação no Inatel e contato.

## Destaques

- HTML, CSS e JavaScript puros, sem framework nem etapa de build
- Layout editorial responsivo
- Animações de entrada ao rolar a página, desligadas para quem usa `prefers-reduced-motion`

## Estrutura

```
index.html            Página única com todas as seções
style.css             Estilos e tokens de cor no topo do arquivo
script.js             Menu, animações e interações
assets/images/        Imagens
```

## Rodar localmente

Abra o `index.html` no navegador, ou sirva a pasta:

```bash
python3 -m http.server 8080
```
